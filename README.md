# 《剑桥雅思11》期末 48h 冲刺复习助手

专为大一公选课期末考打造的手机优先复习网页，零外部依赖、直接部署于 GitHub Pages。

## 在线访问

- **手机/电脑冲刺主页**：https://vataraxl.github.io/ielts11-sprint/
- **A4 可打印配套专项练习卷**：https://vataraxl.github.io/ielts11-sprint/print-pack.html

## 核心功能

1. **考情透视与 48h 打卡日程**：针对听力 16 选 1 原题、阅读 12 选 1–2、写作 8 选 1（不考口语）定制的高性价比冲刺计划，附 20m / 40m 便携模考计时器，并直通 A4 打印练习卷。
2. **听力 16 个 Section 全题库 + 在线音频直达**：内置 IELTS Training Online（免登录原版 S1–S4 MP3 播放器）与 B站按节精准搜词直链，含 3 张地图题方位口诀、陷阱纠偏、遮罩自测模式与老师重点标星筛选。
3. **阅读 12 篇文章题库与官方勘误**：已完整修正原书第 131 页 Test 4 Reading 的 8 处印刷错误（依据 PDF p.144 官方勘误表），附四大题型速通卡。
4. **写作双课件骨架 + 8 题全拆解**：提炼自课堂小作文三步法与大作文四步法 PPT，含 PPT 7 分示范全文、避坑病句对照、一键复制句型及全 8 题改写/分论点提纲。
5. **听力原题拼写听写机（81 词）**：基于浏览器内置 `SpeechSynthesis`（支持 0.85x 慢速与英音优先）和语境挖空提示，拼错自动收入错词本。

## 本地运行

纯静态 ES Module 应用，任意静态服务器即可预览：

```sh
npx serve .
```
